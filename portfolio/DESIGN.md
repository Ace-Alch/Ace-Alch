# GitHub Profile: design record

## Purpose

Provide a clear entry point to engineering projects and repository documentation.

## Elements

| Element | Documentation boundary |
| :-- | :-- |
| Profile introduction | Included in the stated project scope. Implementation details need the corresponding source or design file. |
| Project groups | Included in the stated project scope. Implementation details need the corresponding source or design file. |
| Repository links | Included in the stated project scope. Implementation details need the corresponding source or design file. |

## Technical stack

- GitHub Markdown
- Project navigation
- Portfolio

## Boundaries

Part numbers, interfaces, versions and measured outcomes must come from the original artifacts. They are not inferred from the project title.

## Decisions to recover

Record each design decision with its problem, selected option, rejected options and supporting artifact. Keep the original model or source revision with the record.
